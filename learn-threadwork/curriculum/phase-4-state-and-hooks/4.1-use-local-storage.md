# 4.1 · useLocalStorage hook

**Phase 4:** [State management and hooks](README.md) · **Edit:** `app/client/src/hooks/useLocalStorage.ts` · **Tests:** `tests/phase-4/4.1-use-local-storage.test.ts`

## What you build
A reusable hook that works like `useState` but remembers the value on the device.

The comments in `app/client/src/hooks/useLocalStorage.ts` describe the exact behaviour. The tests in `tests/phase-4/4.1-use-local-storage.test.ts` are the full specification: read them, they're short.

## Steps
1. Pass a function to `useState` so localStorage is read only once.
2. Wrap `JSON.parse` in `try/catch`; any problem means `initial`.
3. In the setter, compute the next value (it may be a function of the previous one), save it in a `try/catch`, and return it.
4. `useCallback` keeps the setter the same between renders.

Run the tests while you work:
```
npm run ex 4.1
```

## See it in the app
The app uses it to remember your sign-in token.

## Checkpoint 0

- [ ] `npm run dev` shows your page; `npm run build` succeeds
- [ ] The project is in git with a sensible `.gitignore`
- [ ] You have used every screen of the finished app and written your own feature list
- [ ] `src/data/` contains the sample JSON
- [ ] `git tag part0`

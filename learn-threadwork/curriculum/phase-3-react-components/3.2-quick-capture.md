# 3.2 · QuickCapture form

**Phase 3:** [React components](README.md) · **Edit:** `app/client/src/components/QuickCapture.tsx` · **Tests:** `tests/phase-3/3.2-quick-capture.test.tsx`

## What you build
The quick-capture bar at the top of the app.

The comments in `app/client/src/components/QuickCapture.tsx` describe the exact behaviour. The tests in `tests/phase-3/3.2-quick-capture.test.tsx` are the full specification: read them, they're short.

## Steps
1. Two pieces of state: the text and the error message.
2. Put `onSubmit` on the `<form>` and call `e.preventDefault()` so the page doesn't reload.
3. Label the input: `<label htmlFor="capture">Capture a task</label>` plus `id="capture"` (you can hide the label visually with the `visually-hidden` class).
4. `useRef` for the input so you can call `.focus()` after adding.

Run the tests while you work:
```
npm run ex 3.2
```

## See it in the app
The bar at the top of the app. Type a task and press Enter.

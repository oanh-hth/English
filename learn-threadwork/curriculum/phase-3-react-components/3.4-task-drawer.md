# 3.4 · TaskDrawer: edit, link and complete

**Phase 3:** [React components](README.md) · **Edit:** `app/client/src/components/TaskDrawer.tsx` · **Tests:** `tests/phase-3/3.4-task-drawer.test.tsx`

## What you build
The task drawer: rename, set importance, link tasks and complete.

The comments in `app/client/src/components/TaskDrawer.tsx` describe the exact behaviour. The tests in `tests/phase-3/3.4-task-drawer.test.tsx` are the full specification: read them, they're short.

## Steps
1. Keep a local `title` state for the input, and sync it with `useEffect` when `task.id` or `task.title` changes.
2. Commit the rename on `onBlur` and when Enter is pressed (`onKeyDown`).
3. For Escape, add a `keydown` listener on `window` in `useEffect` and remove it in the cleanup.
4. The link `<select>` has `value=""`, so it always shows "Choose a task…" after a choice.
5. Build the importance options from `IMPORTANCE` and `GROWTH`.

Run the tests while you work:
```
npm run ex 3.4
```

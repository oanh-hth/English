# 6.2 · A REST API for tasks

**Phase 6:** [Node.js server with Express](README.md) · **Edit:** `app/server/src/routes/tasks.ts` · **Tests:** `tests/phase-6/6.2-tasks-api.test.ts`

## What you build
A REST API for tasks: list, get, create, update and delete.

The comments in `app/server/src/routes/tasks.ts` describe the exact behaviour. The tests in `tests/phase-6/6.2-tasks-api.test.ts` are the full specification: read them, they're short.

## Steps
1. Write a small `wrap(fn)` that calls `fn(req, res).catch(next)`, so async errors reach Express.
2. Validate with `parseTask` and return its error message with 400.
3. Use the right status codes: 201 for created, 204 with `res.status(204).end()` for deleted.
4. `req.params.id` is the `:id` from the URL.

Run the tests while you work:
```
npm run ex 6.2
```

## See it in the app
Mounted at `/api/tasks` (signed-in users only). Try it with curl after signing in, using the token from localStorage.

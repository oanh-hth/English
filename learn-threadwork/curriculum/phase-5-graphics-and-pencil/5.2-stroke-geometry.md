# 5.2 · Stroke width, simplifying and smooth paths

**Phase 5:** [Graphics and Apple Pencil](README.md) · **Edit:** `app/client/src/sketch/geometry.ts` · **Tests:** `tests/phase-5/5.2-stroke-geometry.test.ts`

## What you build
The geometry behind pencil strokes.

The comments in `app/client/src/sketch/geometry.ts` describe the exact behaviour. The tests in `tests/phase-5/5.2-stroke-geometry.test.ts` are the full specification: read them, they're short.

## Steps
1. `strokeWidth`: pick the pressure (pen) or 0.5, then round with `Number(x.toFixed(2))`.
2. `distance`: `Math.hypot(dx, dy)`.
3. `simplify`: compare each point with the last point you *kept*, not the previous point.
4. `toSvgPath`: build the string step by step; round every number with a helper.

Run the tests while you work:
```
npm run ex 5.2
```

## See it in the app
The Sketch tab draws every stroke through `toSvgPath(simplify(...))`.

# 2.2 · The garden reducer: grow, harvest, unlock

**Phase 2:** [Domain logic: dates, garden and rewards](README.md) · **Edit:** `app/shared/garden.ts` · **Tests:** `tests/phase-2/2.2-garden-reducer.test.ts`

## What you build
The garden as a reducer: growing, shrinking, harvesting and choosing the next seed.

The comments in `app/shared/garden.ts` describe the exact behaviour. The tests in `tests/phase-2/2.2-garden-reducer.test.ts` are the full specification: read them, they're short.

## Steps
1. Use `switch (action.type)`. Inside each `case`, TypeScript knows the action's fields.
2. grow: `total = growth + amount`; growth is `Math.min(100, total)`; extra grows by `Math.max(0, total - 100)`.
3. harvest: build the new `harvests` array first, then use it to check whether `nextKind` is unlocked (the harvest you just made counts).
4. Return `state` itself when nothing changes; the tests check this with `toBe`.

Run the tests while you work:
```
npm run ex 2.2
```

## See it in the app
The Harvest button on the garden card, and finishing tasks (via 4.2).

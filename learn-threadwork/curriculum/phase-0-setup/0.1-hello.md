# 0.1 · Make your first test pass

**Phase 0:** [Setup and your first test](README.md) · **Edit:** `app/shared/hello.ts` · **Tests:** `tests/phase-0/0.1-hello.test.ts`

## What you build
A `greet` function. It's tiny on purpose: the point is the loop you will repeat 28 times.

The comments in `app/shared/hello.ts` describe the exact behaviour. The tests in `tests/phase-0/0.1-hello.test.ts` are the full specification: read them, they're short.

## Steps
1. Run `npm install` once in this folder.
2. Run `npm run ex 0.1`. The tests run and stay open, watching for changes.
3. Open `app/shared/hello.ts`, replace the `throw` with a template literal that returns the greeting.
4. Save. The tests run again and turn green.
5. Run `npm run progress` to see your first tick, then commit.

Run the tests while you work:
```
npm run ex 0.1
```

## See it in the app
Run `npm run dev` and open http://localhost:5173. Most of the app says which exercise it is waiting for. That list gets shorter as you go.

## Stuck?
1. Read the failing test's name and the **expected / received** lines.
2. Re-read the lesson section in the [phase README](README.md).
3. Add a `console.log` and look at the test output.
4. Compare with `solutions/shared/hello.ts`, then close it and write it yourself.

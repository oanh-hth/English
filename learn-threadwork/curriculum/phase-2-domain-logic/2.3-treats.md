# 2.3 · Trade fruit for treats

**Phase 2:** [Domain logic: dates, garden and rewards](README.md) · **Edit:** `app/shared/treats.ts` · **Tests:** `tests/phase-2/2.3-treats.test.ts`

## What you build
The treat shop: count the fruit you have and spend it.

The comments in `app/shared/treats.ts` describe the exact behaviour. The tests in `tests/phase-2/2.3-treats.test.ts` are the full specification: read them, they're short.

## Steps
1. `basketCount`: one `reduce` for harvested fruit, one for claimed costs.
2. `claimTreat`: validate the cost first (`Number.isInteger`), then compare with the basket.
3. Return a new wallet with a new `claimed` array; the test checks the old wallet didn't change.
4. `affordable`: `filter` then sort by cost, highest first.

Run the tests while you work:
```
npm run ex 2.3
```

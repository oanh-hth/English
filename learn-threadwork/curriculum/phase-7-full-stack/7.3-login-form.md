# 7.3 · LoginForm with loading and errors

**Phase 7:** [Full stack: connect the app to the server](README.md) · **Edit:** `app/client/src/components/LoginForm.tsx` · **Tests:** `tests/phase-7/7.3-login-form.test.tsx`

## What you build
The sign-in and create-account form, with validation, a waiting state and server errors.

The comments in `app/client/src/components/LoginForm.tsx` describe the exact behaviour. The tests in `tests/phase-7/7.3-login-form.test.tsx` are the full specification: read them, they're short.

## Steps
1. State: email, password, repeat, error, busy.
2. Validate in order and show the first problem; return early.
3. Set `busy` before `await onSubmit(...)`, and clear it in `finally`.
4. Show `err.message` from the rejected promise. The API client (7.1) already turns server errors into readable messages.

Run the tests while you work:
```
npm run ex 7.3
```

## See it in the app
The first screen of the app. Create an account and sign in on your iPad and computer.

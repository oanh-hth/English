# 2.1 · Days, streaks and a thirsty plant

**Phase 2:** [Domain logic: dates, garden and rewards](README.md) · **Edit:** `app/shared/dates.ts` · **Tests:** `tests/phase-2/2.1-dates-and-streaks.test.ts`

## What you build
Day maths and the streak rules.

The comments in `app/shared/dates.ts` describe the exact behaviour. The tests in `tests/phase-2/2.1-dates-and-streaks.test.ts` are the full specification: read them, they're short.

## Steps
1. Write two private helpers: `toUtc(day)` with `Date.UTC(y, m - 1, d)` and `fromUtc(ms)` with `new Date(ms).toISOString().slice(0, 10)`.
2. `addDays`: add `n * 86_400_000` ms. `daysBetween`: subtract and divide, then `Math.round`.
3. `updateStreak`: same day → return the same state; yesterday → +1; anything else → 1.
4. `isThirsty`: all three conditions must be true (grown, has finished something, more than 2 days ago).

Run the tests while you work:
```
npm run ex 2.1
```

## See it in the app
Your streak on the garden card, and the droopy-leaves state when you haven't finished a task for a while.

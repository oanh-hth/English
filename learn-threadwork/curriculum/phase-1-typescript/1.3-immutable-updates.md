# 1.3 · Link, move and delete tasks without mutation

**Phase 1:** [TypeScript through the task model](README.md) · **Edit:** `app/shared/task-ops.ts` · **Tests:** `tests/phase-1/1.3-immutable-updates.test.ts`

## What you build
Functions that change the task list the safe way: link, unlink, move, delete, and mark resources as used.

The comments in `app/shared/task-ops.ts` describe the exact behaviour. The tests in `tests/phase-1/1.3-immutable-updates.test.ts` are the full specification: read them, they're short.

## Steps
1. The tests freeze the input with `Object.freeze`: any mutation throws. If you see "Cannot assign to read only property", you changed an input.
2. Use `tasks.map(...)` and return the same task object for tasks you don't change.
3. For links, update both tasks in one `map`: the one with id `a` gets `b`, the one with id `b` gets `a`.
4. `deleteTask`: `filter` out the task, then `map` the rest to remove the id from their links.

Run the tests while you work:
```
npm run ex 1.3
```

## See it in the app
Linking in the drawer, the move buttons on the board and deleting all go through these functions (via the reducer in 4.2).

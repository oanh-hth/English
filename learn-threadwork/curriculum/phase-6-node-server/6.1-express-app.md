# 6.1 · An Express app with health check and errors

**Phase 6:** [Node.js server with Express](README.md) · **Edit:** `app/server/src/app.ts` · **Tests:** `tests/phase-6/6.1-express-app.test.ts`

## What you build
The Express app that every server feature plugs into.

The comments in `app/server/src/app.ts` describe the exact behaviour. The tests in `tests/phase-6/6.1-express-app.test.ts` are the full specification: read them, they're short.

## Steps
1. Order matters: JSON parser, health route, `mount(app)`, the `/api` 404, then the error handler.
2. The 404 is `app.use("/api", ...)` *after* all routes.
3. The error handler must have four parameters, even if you don't use `next`.
4. Express sets `err.type = "entity.parse.failed"` for broken JSON.

Run the tests while you work:
```
npm run ex 6.1
```

## See it in the app
Run `npm run dev:server` and open http://localhost:3001/api/health.

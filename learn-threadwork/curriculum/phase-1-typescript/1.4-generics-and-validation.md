# 1.4 · groupBy, sorting and parsing unknown data

**Phase 1:** [TypeScript through the task model](README.md) · **Edit:** `app/shared/collections.ts` · **Tests:** `tests/phase-1/1.4-generics-and-validation.test.ts`

## What you build
Three general tools: `groupBy` (generic), `sortByDue`, and `parseTask`, which turns untrusted data into a `Task` or a clear error.

The comments in `app/shared/collections.ts` describe the exact behaviour. The tests in `tests/phase-1/1.4-generics-and-validation.test.ts` are the full specification: read them, they're short.

## Steps
1. `groupBy`: start with `{} as Record<K, T[]>`, add an empty array for each listed key, then push each item into its group (`??=` helps).
2. `sortByDue`: copy first (`[...tasks]`), then sort. `null` dates go last. Strings like "2026-11-02" compare correctly with `<`.
3. `parseTask`: check it is a plain object (not null, not an array). Then check each required field in the order of the error list, and return the first error.
4. Optional fields: use the value only when it has the right type, else the default. Keep only strings in `links`.

Run the tests while you work:
```
npm run ex 1.4
```

## See it in the app
The server's tasks API (6.2) uses `parseTask` to reject bad requests.

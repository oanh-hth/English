# 5.1 · Draw the plant with SVG

**Phase 5:** [Graphics and Apple Pencil](README.md) · **Edit:** `app/client/src/components/Plant.tsx` · **Tests:** `tests/phase-5/5.1-plant.test.tsx`

## What you build
The plant: a pure function that decides the parts, and an SVG component that draws them.

The comments in `app/client/src/components/Plant.tsx` describe the exact behaviour. The tests in `tests/phase-5/5.1-plant.test.tsx` are the full specification: read them, they're short.

## Steps
1. Write `plantParts` first and get its tests green; it is plain maths.
2. Flowers turn into fruit: compute fruits, then `flowers = max(0, blooms - fruits)`.
3. In `Plant`, compute the parts and use `Array.from({ length: n }, (_, i) => ...)` to draw each one with its `data-part`.
4. Shapes are up to you. Start with circles and ellipses, then make it pretty.

Run the tests while you work:
```
npm run ex 5.1
```

## See it in the app
The garden card, and the slider in the playground.

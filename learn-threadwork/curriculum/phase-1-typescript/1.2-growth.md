# 1.2 · Growth per importance and plant stages

**Phase 1:** [TypeScript through the task model](README.md) · **Edit:** `app/shared/growth.ts` · **Tests:** `tests/phase-1/1.2-growth.test.ts`

## What you build
The reward rule: how much the plant grows for each importance, and which stage a growth value is.

The comments in `app/shared/growth.ts` describe the exact behaviour. The tests in `tests/phase-1/1.2-growth.test.ts` are the full specification: read them, they're short.

## Steps
1. Fill in `GROWTH` and remove the `as Record<...>` cast at the end. If you forget a key, TypeScript now tells you.
2. `stageOf`: clamp the value to 0..100, then walk `STAGES` and keep the last stage whose start is ≤ growth.
3. `nextStage`: `STAGES.find(([at]) => at > g)` gives the next one, or `undefined` at 100.

Run the tests while you work:
```
npm run ex 1.2
```

## See it in the app
The drawer's importance menu ("High · +25%") and the garden card ("7% to fruiting") use these.

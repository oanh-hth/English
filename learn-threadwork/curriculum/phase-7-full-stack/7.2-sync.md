# 7.2 · Sync decisions and debounce

**Phase 7:** [Full stack: connect the app to the server](README.md) · **Edit:** `app/shared/sync.ts` · **Tests:** `tests/phase-7/7.2-sync.test.ts`

## What you build
The rules for syncing two devices, and `debounce` for saving after you stop typing.

The comments in `app/shared/sync.ts` describe the exact behaviour. The tests in `tests/phase-7/7.2-sync.test.ts` are the full specification: read them, they're short.

## Steps
1. Equal timestamps: nothing to do. Then work out `localChanged` and `remoteChanged` (each compared with `lastSyncedAt`).
2. Both changed: conflict. One changed: push or pull. Neither: the newer one wins.
3. `debounce`: keep the timer and the last arguments in variables closed over by the returned function.
4. `Object.assign(call, { flush, cancel })` adds methods to a function.

Run the tests while you work:
```
npm run ex 7.2
```

## See it in the app
The "Synced" label in the top bar, and the conflict banner when two devices disagree.

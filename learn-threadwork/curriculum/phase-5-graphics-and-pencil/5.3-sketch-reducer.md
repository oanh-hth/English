# 5.3 · Pencil input with palm rejection

**Phase 5:** [Graphics and Apple Pencil](README.md) · **Edit:** `app/client/src/sketch/sketchReducer.ts` · **Tests:** `tests/phase-5/5.3-sketch-reducer.test.ts`

## What you build
The input logic for drawing, with palm rejection, undo and redo.

The comments in `app/client/src/sketch/sketchReducer.ts` describe the exact behaviour. The tests in `tests/phase-5/5.3-sketch-reducer.test.ts` are the full specification: read them, they're short.

## Steps
1. Handle `penSeen` first in `down`: it becomes true when a pen touches, and stays true.
2. Then ignore touch when `penSeen`, and ignore any second pointer while one is drawing.
3. `up` only finishes the stroke of the active pointer.
4. Undo moves the last stroke to `undone`; a new stroke clears `undone`.

Run the tests while you work:
```
npm run ex 5.3
```

## See it in the app
The Sketch tab. Try it on the iPad: rest your hand on the screen while drawing with the pencil.

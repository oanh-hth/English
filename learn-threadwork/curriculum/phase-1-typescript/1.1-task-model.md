# 1.1 · Create tasks and check importance

**Phase 1:** [TypeScript through the task model](README.md) · **Edit:** `app/shared/task-factory.ts` · **Tests:** `tests/phase-1/1.1-task-model.test.ts`

## What you build
`createTask`, the one place new tasks are made, and `isImportance`, a check you will use to validate data from outside.

The comments in `app/shared/task-factory.ts` describe the exact behaviour. The tests in `tests/phase-1/1.1-task-model.test.ts` are the full specification: read them, they're short.

## Steps
1. Read `app/shared/types.ts` first: every field of `Task` is explained there.
2. Return an object literal with every field. Use `title.trim() || "Untitled task"`.
3. Use `??` for defaults so only missing values get the default.
4. For `isImportance`, check `typeof value === "string"` first, then `(IMPORTANCE as readonly string[]).includes(value)`. The cast is needed because `as const` makes the array type very narrow.

Run the tests while you work:
```
npm run ex 1.1
```

## See it in the app
Every task in the app is created through this function (the quick-capture bar dispatches `addTask`, and exercise 4.2 calls `createTask`).

# 4.2 · The app reducer

**Phase 4:** [State management and hooks](README.md) · **Edit:** `app/client/src/state/appReducer.ts` · **Tests:** `tests/phase-4/4.2-app-reducer.test.ts`

## What you build
One reducer for the whole app, built from your Phase 1 and 2 functions.

The comments in `app/client/src/state/appReducer.ts` describe the exact behaviour. The tests in `tests/phase-4/4.2-app-reducer.test.ts` are the full specification: read them, they're short.

## Steps
1. Import what you need: `createTask`, `linkTasks`, `moveTask`, `growthFor`, `FOCUS_GROWTH`, `updateStreak`, `gardenReducer`.
2. Write a small helper `update(tasks, id, fn)` for rename and setImportance.
3. For move: find the task *before* moving it, to know its old status and importance.
4. Delegate: the reducer mostly calls functions you already wrote. That is the point of Phases 1 and 2.

Run the tests while you work:
```
npm run ex 4.2
```

## See it in the app
Everything you do in the app becomes an action handled here.

# 6.3 · Password hashing, tokens and protected routes

**Phase 6:** [Node.js server with Express](README.md) · **Edit:** `app/server/src/auth.ts` · **Tests:** `tests/phase-6/6.3-auth.test.ts`

## What you build
Accounts: hashing passwords, signing tokens, protecting routes, register and login.

The comments in `app/server/src/auth.ts` describe the exact behaviour. The tests in `tests/phase-6/6.3-auth.test.ts` are the full specification: read them, they're short.

## Steps
1. Hash: `randomBytes(16)` salt, `await scrypt(password, salt, 32)`, join with `$`.
2. Verify: split, check the parts, hash again with the stored salt, compare with `timingSafeEqual` (lengths must match first).
3. Token: `Buffer.from(JSON.stringify(payload)).toString("base64url")`, then the HMAC of that string with `createHmac("sha256", secret)`.
4. Verify the signature before you trust anything in the payload; then check `exp`. Wrap it all in `try/catch` and return `null`.
5. Login gives the same message for an unknown email and a wrong password, so nobody can find out which emails have accounts.

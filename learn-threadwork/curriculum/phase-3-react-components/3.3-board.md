# 3.3 · Board with columns and move buttons

**Phase 3:** [React components](README.md) · **Edit:** `app/client/src/components/Board.tsx` · **Tests:** `tests/phase-3/3.3-board.test.tsx`

## What you build
The board: three columns, cards, and move buttons that work well with fingers and pencil.

The comments in `app/client/src/components/Board.tsx` describe the exact behaviour. The tests in `tests/phase-3/3.3-board.test.tsx` are the full specification: read them, they're short.

## Steps
1. Map over `COLUMNS`; for each, `filter` the tasks with that status.
2. `<section aria-label={col.name}>` makes each column a landmark the tests (and screen readers) can find.
3. Render a `TaskCard` per task and a small row of move buttons for the other two columns.
4. Every element in a list needs a `key`: the column status, the task id.

Run the tests while you work:
```
npm run ex 3.3
```

## See it in the app
The main Tasks view.

# Tài liệu Phòng Trữ Đồ

Phòng Trữ Đồ là web app tiếng Việt biến những thứ bạn đã mua thành đồ vật trong một căn phòng mô phỏng (2D và 3D), nhắc món sắp hết hạn, đọc hoá đơn và so sánh chi tiêu theo tháng.

| Bạn muốn | Đọc |
| --- | --- |
| Biết cách dùng app, từng bước | [Hướng dẫn sử dụng](user-guide.md) |
| Biết 16 nhóm đồ và mọi quy tắc nhắc nhở (Miso, Misu, mua lại, hết hạn, chi tiêu) | [Nhóm đồ và quy tắc](rules.md) |
| Biết app đọc hoá đơn thế nào, thêm một kiểu hoá đơn mới | [Đọc hoá đơn](bills.md) |
| Chạy, đưa lên host, sửa code, thêm nhóm hoặc kiểu phòng mới | [Tài liệu kỹ thuật](technical.md) |
| Xem lịch sử thay đổi | [Nhật ký thay đổi](changelog.md) |

Ngoài thư mục này, `../README.md` (thư mục `room/`) là trang giới thiệu ngắn và cách chạy nhanh.

Product brief (mục tiêu, người dùng, phạm vi, rủi ro, lộ trình) nằm ở một tài liệu riêng để review, không nằm trong repo.

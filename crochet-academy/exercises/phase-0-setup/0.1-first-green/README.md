# 0.1 · Your first green test

**Goal:** learn the loop you will use for every exercise: read, run the tests (red), write code, run again (green).

**File to edit:** `src/core/welcome.ts`

## What to build
`welcome(name)` returns `Welcome to the nook, <name>!`. An empty or blank name becomes `friend`.

## The loop
1. Run `npm run learn test 0.1` and watch it fail. The message says "Exercise 0.1 is not built yet".
2. Replace the `todo('0.1')` line with real code.
3. Run the command again until everything is green.
4. Run `npm run learn` to see the exercise ticked in your checklist.

## Done when
All 3 tests pass.

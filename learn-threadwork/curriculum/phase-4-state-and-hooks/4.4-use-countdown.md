**Phase 4:** [State management and hooks](README.md) · **Edit:** `app/client/src/hooks/useCountdown.ts` · **Tests:** `tests/phase-4/4.4-use-countdown.test.ts`

## What you build
A focus timer hook.

The comments in `app/client/src/hooks/useCountdown.ts` describe the exact behaviour. The tests in `tests/phase-4/4.4-use-countdown.test.ts` are the full specification: read them, they're short.

## Steps
1. Two states: `remaining` and `running`.
2. One effect starts a `setInterval` while running and clears it in the cleanup.
3. A second effect watches `remaining`: at 0, stop, reset and call `onDone` (from a ref, so it is always the latest).
4. `start`, `pause`, `reset` just set state.

Run the tests while you work:
```
npm run ex 4.4
```

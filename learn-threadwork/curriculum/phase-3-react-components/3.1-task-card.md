**Phase 3:** [React components](README.md) · **Edit:** `app/client/src/components/TaskCard.tsx` · **Tests:** `tests/phase-3/3.1-task-card.test.tsx`

## What you build
Your first React component: a card that shows one task.

The comments in `app/client/src/components/TaskCard.tsx` describe the exact behaviour. The tests in `tests/phase-3/3.1-task-card.test.tsx` are the full specification: read them, they're short.

## Steps
1. Return a `<button type="button">` with `data-status={task.status}` and an `onClick` that calls `onOpen(task.id)`.
2. Inside: `<h3>{task.title}</h3>` and a row of small spans.
3. Use `dueLabel(task.due, today)` and render it only when it is not empty.
4. Watch out for `{task.links.length && ...}`: it renders a `0`. Compare with `> 0`.

Run the tests while you work:
```
npm run ex 3.1
```

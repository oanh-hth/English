# 2.4 · Badges from your history

**Phase 2:** [Domain logic: dates, garden and rewards](README.md) · **Edit:** `app/shared/badges.ts` · **Tests:** `tests/phase-2/2.4-badges.test.ts`

## What you build
Statistics from your tasks and garden, and badges computed from them.

The comments in `app/shared/badges.ts` describe the exact behaviour. The tests in `tests/phase-2/2.4-badges.test.ts` are the full specification: read them, they're short.

## Steps
1. `linkPairs`: every link is stored on both tasks, so count all links and divide by 2.
2. `earnedBadges`: `BADGES.filter(b => b.earned(stats)).map(b => b.id)`.
3. `newBadges`: put the earlier badges in a `Set` and keep only the new ones.

Run the tests while you work:
```
npm run ex 2.4
```

## See it in the app
Capstone: show a toast when `newBadges` finds something after an action.

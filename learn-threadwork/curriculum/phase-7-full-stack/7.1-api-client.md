# 7.1 · A typed API client

**Phase 7:** [Full stack: connect the app to the server](README.md) · **Edit:** `app/client/src/api/client.ts` · **Tests:** `tests/phase-7/7.1-api-client.test.ts`

## What you build
A typed API client that every screen uses to talk to the server.

The comments in `app/client/src/api/client.ts` describe the exact behaviour. The tests in `tests/phase-7/7.1-api-client.test.ts` are the full specification: read them, they're short.

## Steps
1. Write one private `request<T>(method, path, body?)` and build every method on it.
2. Add `Content-Type` only when there is a body, and `Authorization` only when there is a token.
3. `try/catch` only around `fetch` itself (network errors). HTTP errors are handled with `res.ok`.
4. Read the error body with `res.json().catch(() => null)`; HTML error pages are not JSON.

Run the tests while you work:
```
npm run ex 7.1
```

## See it in the app
Sign-in, loading and saving your data, and the weather card.

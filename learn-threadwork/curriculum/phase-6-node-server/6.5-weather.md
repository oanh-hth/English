# 6.5 · Weather from Open-Meteo with a cache

**Phase 6:** [Node.js server with Express](README.md) · **Edit:** `app/server/src/weather.ts` · **Tests:** `tests/phase-6/6.5-weather.test.ts`

## What you build
A weather endpoint that calls Open-Meteo and caches the answers.

The comments in `app/server/src/weather.ts` describe the exact behaviour. The tests in `tests/phase-6/6.5-weather.test.ts` are the full specification: read them, they're short.

## Steps
1. `weatherKind`: check snow, then rain, then wind, then cloud, in that order.
2. The service keeps a `Map` from "lat,lon" (rounded) to `{ at, value }`.
3. Use the injected `fetchFn` and `now`, never the global ones, so the tests can control them.
4. The router turns query strings into numbers with `Number(...)` and checks `Number.isFinite` and the ranges.

Run the tests while you work:
```
npm run ex 6.5
```
